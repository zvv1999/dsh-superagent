- 保留当前运行版本的来源接入、只读订阅、心跳探测与历史缺口回归覆盖。上下文配置脚本支持调用者指定 GitHub/GitLab 项目和本机管理地址；测试核对部署身份隔离与默认文本迁移摘要。
- 实机只读验证：通过本人钉钉授权读取告警群历史，将消息发送者 ID 与群机器人列表比对，确认本人读取能包含机器人消息；对应群订阅正常检查并记录了新增。公开记录仅保留验证结论。
- 新增明确选择订阅的任务处理开关，复用既有观察／自动接单与规则门；卡片显示研判输入数，并链接到既有接单设置和完整处理记录。中文指南、授权约束及架构索引已同步。
- 回归覆盖默认上下文模式、真实 Runtime 中的机器人观察输入、观察模式无派工、自动模式规则接单、关闭／来源禁用、撤销范围、重复与重叠订阅、页面检查点回滚、无文本消息以及界面跳转。
- 补充全生命周期回归：新消息轮询 → 规则接单 → Worker 阻塞 → 操作者重试 → 完成报告，核对同一工单保留两次执行报告、输入去重及零群消息发送。界面同时覆盖单次执行的完整报告、历史报告、中英文显示及报告换行；实机浏览器确认两份长报告没有单行截断或横向溢出。报告工具拒绝带未解决人工请求的丢弃结单。
- 本机真实验证：通过本人授权读取选定告警群，将最近一条既有机器人告警显式送入研判，Router 匹配诊断规则并创建工单，Worker 实际启动；浏览器走查订阅 → 触发 → 决策 → 工单 → Worker Session。验证窗口内没有新的自然告警到达，显式回放不能代替自然到达的实机验收；自然轮询后的完整生命周期另由 Runtime 回归覆盖。本次诊断因详情接口需要身份授权，未取得原始 Trace，不能据此认定告警故障已经修复。诊断证据记录在操作者本机工单中。
- 修正本机已有的 Worker 提示词覆盖后，操作者的继续请求由 Router 关联回原工单，恢复同一 Worker 和执行目录，实际报告为受阻。工单保留两次执行报告并提供重试入口；没有重复建单或发送群消息。受阻报告更正了先前将缺证据误作无需处理的结论，原始告警仍待正常后台登录和 Trace 取证。
- 私有项目资料、设备/部署记录、私人文档链接、真实身份测试样例已移除或换为模板。凭证、数据库、聊天历史、日志、构建物和 node_modules 不在公开提交中。

依赖 UI primitives 缺失 sourcemap 的警告不影响测试和构建。Windows 未实机验证。隔离 profile 检查不等同于真实模型和消息平台端到端验收；每位使用者仍需配置自己的模型、项目权限和消息平台授权，再按中文上手指南完成实际任务验证。
