# Upstream and publication scope

Community customization of [deepseek-ai/dsh-superagent-prototype](https://github.com/deepseek-ai/dsh-superagent-prototype), based on upstream commit `8c32a9d`. This is not an official DeepSeek release. The original MIT license and copyright remain in [LICENSE](LICENSE).

Customizations include GitLab, DingTalk Stream, personal WeChat, personal Feishu OAuth reads, personal DingTalk reads/subscriptions, connection management, named group selection, role context assembly and regression coverage. Prepared from the working installation on November 11, 2026.

Contains code, tests, public guides and reusable configuration templates. Credentials, messages, databases, private project material, internal deployment records, logs and model gateway settings are excluded. Example identities and fixture names are illustrative. Each operator supplies their own accounts, model provider, project access and messaging consent.
